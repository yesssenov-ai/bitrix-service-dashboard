# Модуль «Логистика» — финальные правки + 2 глобальных фикса

## Что в архиве (кладём поверх файлов в репозитории, сохраняя пути)

| Файл | Что изменилось |
|---|---|
| `logistics-calc.js` | (1) фикс `ymd` — теперь понимает Date-объекты из Postgres → **заработал фильтр по Годам, дедлайны и прогноз**; (2) убран дубль «Пакинг-лист» в документах; (3) живой резолвер имён менеджеров (`resolveUserNames`/`uname`) — больше нет «#49/#66/#92» |
| `logistics-notify.js` | Руководитель сейлса берётся из **оргструктуры** (user.get → отдел → глава отдела) и получает уведомление. Получатели: ответственный за сделку + ответственный за закупку + руководитель сейлса (фолбэк — координаторы) |
| `public/logistics.html` | Кнопка **«Экспорт»** — красивая выгрузка текущего отфильтрованного списка в Excel (.xlsx) со всеми стадиями, датами, сроками, прогнозом, автофильтром |
| `routes/logistics-routes.js` | Роут `GET /api/logistics/board` (кэш, `?force=1` — пересчёт) |
| `public/portal.html` | Карточки «Контракты» и «Логистика» на портале |
| `constants.js` | **ГЛОБАЛЬНЫЙ фикс имён**: при старте сервера дозагружаем полный справочник сотрудников из Bitrix и дописываем недостающие имена в общий `USERS`. Чинит «#id» во ВСЕХ модулях сразу |
| `server.js` | Роуты и расписание Логистики; вызов `hydrateUsers()` при старте; ночное полное обновление |

## Деплой (как обычно, со своей машины)

```bash
cd D:\PLS\2026\bitrix-dashboard\bitrix-dashboard
# распаковать архив поверх, сохранив пути
git status                 # проверить, что затронуты только файлы из таблицы выше
git add -A
git commit -m "Логистика: экспорт в Excel, фикс Год/дедлайнов, руководитель сейлса в уведомлениях + глобальный справочник имён"
git push
```

Railway задеплоит `master` автоматически. После старта в логах будет строка
`USERS: дозагружено сотрудников из Bitrix — N` — это подтверждение, что имена подтянулись.

## Проверка после деплоя
1. Открыть `/logistics.html` → фильтр «Год» больше не пустой, у заказов видно «🎯 сдать до …».
2. Менеджеры отображаются по именам (не «#49»). То же на других модулях.
3. Кнопка «Экспорт» в шапке → скачивается `Логистика_ГГГГ-ММ-ДД.xlsx`.
4. В карточке заказа документы без дубля «Пакинг-лист».
